## Site Structure

```
marjiya-auto/
├── _config.yml          # Jekyll configuration
├── _layouts/            # Page templates
├── _includes/           # Shared components
├── _data/               # Brand, model, category, location data
├── assets/css/          # Design system stylesheet
├── assets/js/           # JavaScript (animations, tracking)
├── brands/              # 6 brand pages (Bajaj, Yamaha, Honda, Hero, TVS, Suzuki)
├── models/              # 16 model pages
├── categories/          # 18 part category pages
├── locations/           # 8 city delivery pages
├── products/            # Product pages (1 sample + index)
├── about/               # About + Trust page
├── index.html           # Homepage
├── robots.txt           # SEO crawl directives
├── sitemap.xml          # Complete URL map
└── Gemfile              # Jekyll dependencies
```

## Setup

1. Clone this repo
2. Run `bundle install`
3. Run `bundle exec jekyll serve`
4. Visit `http://localhost:4000/marjiya-auto/`

## GitHub Pages Deployment

Push to `main` branch → GitHub Pages auto-builds and deploys.

## Configuration

Edit `_config.yml` to update:
- Google Analytics ID (`google_analytics`)
- Phone numbers
- Social media links
- Business details

## Adding Products

Create a new file: `products/[slug]/index.html`
Use `layout: product` and fill in front matter fields.

## Adding Blog Posts

Create files in `_posts/` with format: `YYYY-MM-DD-title.md`
Use `layout: default` or create a `post` layout.
